# ChromeBook-install-apps

Script utilisé dans [ce blog](https://smorel.net/TODO) afin d'installer des applications sur votre ChromeBook.

Ce qu'il fait :
- Installation du certificat réseau de la Région Île de France (pas encore totalement testé)
- Télécharge puis installe des logiciels facilement sur votre ChromeBook depuis l'environnement linux

Si vous avez la moindre suggestion à faire, comme rajouter des applications, changer la liste d'application minimal ou d'autres choses qui peuvent être amélioré, n'hésitez pas à [ouvrir un ticket](https://github.com/NowYouKnow-nYk/ChromeBook-install-apps/issues), ou de [faire une pull request](https://github.com/NowYouKnow-nYk/ChromeBook-install-apps/pulls)
